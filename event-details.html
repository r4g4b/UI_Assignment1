Web Penetration Testing Workshop

Description

A hands-on workshop where you learn how to find and exploit common web vulnerabilities such as SQL injection, XSS and broken authentication in a safe lab.

Event Information

  • Date: 15 November 2026
  • Time: 10:00 AM - 1:00 PM
  • Venue: Lab 3, Engineering Building
  • Entry: Free for students (bring your student ID and a laptop)

Agenda

  1. 10:00 - Introduction to web security
  2. 10:30 - Recon and scanning
  3. 11:15 - Exploiting SQL injection and XSS
  4. 12:15 - Mini challenge
  5. 12:45 - Q and A
